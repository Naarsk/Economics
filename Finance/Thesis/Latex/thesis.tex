\section{LLM and Computational Setup}\label{sec:llm-and-computational-setup}
    Experiments were conducted using two large language models: Deepseek-R1 8B (see~\ref{lst:deepseek-r1}) and GPT-OSS 20B (see~\ref{lst:gptoss}), both run on the University of Luxembourg High-Performance Computing cluster (ULHPC).
    Additionally, Deepseek 8B was tested on a local machine for comparison.
    Both models were evaluated on summarization and forecasting tasks, and their outputs were broadly comparable, indicating that either model could effectively support the workflow.
    The models were chosen for their ability to \textit{think} and to handle long-context inputs, which is essential given that the average document in our dataset spans roughly 15 pages, corresponding to approximately 80,000 tokens.
    The hardware setup differed between environments.
    On the local machine, inference was carried out on an NVIDIA GeForce GTX~1070 GPU with 8\,GB of VRAM (CUDA~12.8), which limited the feasible model size and imposed a maximum context length of 2,048 tokens for Deepseek~8B.
    This required documents to be split into multiple segments for processing.
    In contrast, the ULHPC nodes were equipped with NVIDIA Tesla V100-SXM2 GPUs with 32\,GB of VRAM  (CUDA~12.7), offering four times the memory capacity and significantly greater compute throughput.
    This enabled the use of both Deepseek~8B and GPT-OSS~20B with extended context lengths of up to 131,072 tokens, allowing entire documents to be processed in a single pass with batch inference, thereby reducing preprocessing overhead and improving throughput.
    All the models were accessed through an Ollama API.
